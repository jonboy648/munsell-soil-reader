# Frame batch files

One CSV per print batch of the frame, named for the batch code printed on the frame
(`LOT-A1.csv`). The app looks the code up here. The format, and how a batch is measured, are in
[docs/frame-batches.md](../../../docs/frame-batches.md).

No batch has been measured yet, so there are no files here, and every frame is refused as a Card
until one is added. Do not put made-up values here: a made-up batch is a wrong correction.
