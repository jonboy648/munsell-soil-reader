# The soil book page can be the card

The people this tool is for already own the Munsell soil book, and most don't own an X-Rite ColorChecker. So a page of the book is a supported card next to the ColorChecker. The app knows every chip's notation, so the page's chips serve as reference colors for the correction. This means correcting against the same book the answer is read from. That is deliberate: the chips sit in exactly the colors soil has, and the user needs nothing extra to buy.

## Consequences

- One page holds one hue. The correction is strongest near that hue, so the user should lay down the page closest to the soil, as they would when reading by eye.
- Books fade and get dirty over the years. A worn page shifts every reading, and the card check can't detect a uniformly faded page. The ColorChecker stays supported as the independent reference.
- Page layouts belong to an edition: chips sit in value rows and chroma columns, with gaps. We build to the 2009 and later edition.
